# 序理

一个供个人长期使用的思维记录、评估与训练系统。

它围绕真实思维活动建立闭环：

> 自由记录 → 原文保存 → 结构重建 → 证据驱动评估 → 逐轮复盘 → 针对性训练 → 即时再评估 → 长期追踪

## 当前 MVP

- 首页：稳定思维质量、九项标准、结构习惯、成长曲线、问题模式与最近记录
- 思维记录：保存原文、历史记录和完整档案状态
- 新建记录：低负担记录 / 深度复盘双模式
- 分析：先还原 8 个思维元素，再按证据选择 Element × Standard 组合评估
- 复盘与训练：一次一个问题，聚焦一个主要标准
- 成长分析：区分稳定实线与训练后即时虚线
- 训练专题：累积长期问题、案例与训练进度
- 知识与方法：先给归类和修改建议，确认后才进入正式体系
- 评估体系：Critical Thinking Base V1.0，可另存为新版本

## 数据原则

结构化数据保存在 D1 中。核心表位于 `db/schema.ts`：

- `thinking_records`：思维活动原文与当前档案状态
- `analysis_versions`：不可覆盖的分析版本
- `conversation_turns`：复盘对话
- `training_sessions`：训练前后评分
- `training_topics`：长期训练专题
- `assessment_frameworks`：评估体系版本

数据库迁移位于 `drizzle/`。API 位于 `app/api/`。

## 评估框架

V1.0 严格分为三层：

1. 8 个思维元素：目的、问题、信息、解释与推理、概念、假设、结果与意义、观点
2. 9 个思维标准：清晰性、准确性、精确性、相关性、深度、广度、逻辑性、重要性、公正性
3. 5 个综合能力：批判性思维、逻辑推理、问题分析、决策能力、反思能力

没有足够证据时显示“暂不评价”，不使用低分代替。

## 继续开发

项目使用 Node.js 22+ 与 pnpm。

```bash
pnpm install
pnpm run dev
pnpm run db:generate
pnpm run build
```

主要修改入口：

- 产品交互与模拟数据：`app/components/ThoughtLabApp.tsx`
- 视觉样式：`app/globals.css`
- 持久化接口：`app/api/`
- 数据结构：`db/schema.ts`

## 接入真正的大语言模型

当前分析和训练内容为可交互模拟。后续接入模型时，建议保留现有前端数据形状，在服务端增加一个分析适配层：

1. 先写入 `thinking_records`
2. 模型阶段一只输出结构重建
3. 用户确认后，阶段二输出证据充分的评估组合
4. 服务端校验结构化结果，异常时保留原文并允许重试
5. 每次分析都新增 `analysis_versions`，不覆盖旧结果

这样可以替换模型或提示词，而无需重写产品界面。
